# Grok and Kimi harness qualification

## Scope — November 15, 2026

Grok initially admits only the observed **Fast** option; Kimi admits **Instant**
(`k28-instant`). Grok and Groq are separate providers. Groq remains paused.
Full browser, terminal and file-editing qualification is pending the installed
candidate's independent workflow checks.

Each Grok inference uses one fresh Private Chat in the shared signed-in profile.
The adapter observes Private mode before Send. Because Grok removes that control
after Send, later observations require the native one-shot submission claim,
the same page generation and exact root, the selected model, and the complete
outbound prompt fingerprint. A route excursion, changed prompt/model, reload or
contradictory mode revokes authority. The adapter accepts literal code only after
the owned response footer, completion announcement and idle composer agree.
Cleanup closes the verified owned private page; it does not invoke saved-chat
deletion or promise server-side erasure. Local transcripts remain in Computa.
